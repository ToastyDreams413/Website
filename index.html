Some Things I've Made

Rookie: AI Chess Commentary Generator

Project Lead

A fine-tuned T5 model that turns Stockfish engine signals into grounded natural-language move commentary, preferred over GPT-4o-mini by 73.7% of human evaluators.

Hugging Face Github

Rookie grounds language generation in engine analysis rather than letting a model narrate from the board alone. For every position I extract 27 engine-derived features (evaluation swing, win-percentage delta, checks, captures, hanging pieces, mobility change, trades, positional gains), so each explanation traces back to a measurable signal.

Deterministic templates over those features produced 3.9M+ synthetic commentaries from 197K+ FEN positions, which I used to fine-tune a T5-small seq2seq model. Benchmarked against GPT-4o-mini on 1,000 held-out positions, it won 69.6% preference from a Gemini-2.5-Flash LLM judge and 73.7% from human chess players, scored on faithfulness, relevance, informativeness, clarity, and conciseness.

Orion: AI Threat Assessment System

Sole Developer

A full-stack threat assessment simulator that tracks airborne objects on a live map, scores them against a multi-factor risk model, and pairs the score with an LLM advisor that explains it.

Live Demo Github

Orion simulates aircraft and unidentified tracks over a live map, modeling each object by location, altitude, heading, intent, capability, and anomalous behavior. Those attributes feed a weighted scoring model that produces a continuous threat estimate, so an operator can see not just the ranking but the factors driving it.

The harder part was explainability, since a raw threat score isn't much use if you can't say where it came from. I wired the LLM advisor to the same feature vector the scorer reads, so it can answer questions about a specific track, walk through why that track ranked where it did, and suggest a response without contradicting the model underneath it.

Geometric Computer Vision Pipeline

Sole Developer

An end-to-end classical vision pipeline (ORB feature matching, RANSAC homography estimation, inverse warping, blending) with debug tooling built to work out where alignment fails.

Github

I consolidated several computer vision assignments into one coherent pipeline: ORB feature detection and matching, RANSAC-based homography estimation, inverse warping, and multi-band blending for panorama construction.

Getting a panorama to stitch is easy. Working out why it didn't is the hard part, so I built visual debug tooling for match correspondences, RANSAC inlier masks, and every intermediate warp stage. That turned the usual failure cases (repetitive textures, low parallax, motion blur) into something I could actually diagnose instead of guess at.

Monte Carlo Tree Search Visualization

Sole Developer

An interactive demo that renders Monte Carlo Tree Search step by step, exposing how visit counts and value estimates converge on a decision.

Live Demo Github

MCTS underpins a lot of game AI and planning, but its behavior is hard to reason about from pseudocode alone. This demo animates all four phases (selection, expansion, rollout, backpropagation) so you can watch the tree's statistics build up instead of inferring them from pseudocode.

Every node shows its value estimate and visit count, and the path the search currently favors is highlighted as it shifts, which makes the exploration/exploitation tradeoff in UCT easy to see as it happens.
